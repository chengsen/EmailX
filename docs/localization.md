# EmailX 本地化与语言设置

在“设置 → 通用 → 语言”选择“跟随系统”“简体中文”或“English”。选择后立即保存，下次启动 EmailX 生效。当前窗口不会立即刷新语言，请完成正在进行的邮件操作后自行退出并重新打开。

“跟随系统”移除 EmailX 的应用语言覆盖，恢复 macOS 原生语言选择规则。手动选择只修改 EmailX 自身的 `AppleLanguages` 偏好，不修改系统语言。现有俄语资源保留，可由系统语言规则选择，但不出现在应用手动选择列表中。

## 实现范围

界面、菜单、工具栏、设置、系统邮件文件夹名称和账户错误提示使用 Apple String Catalog：`MyEmail/Resources/Localizable.xcstrings`。SwiftUI 使用可本地化文本；动态字符串与 AppKit 标签使用 `String(localized:)`。数量变化使用目录复数规则，日期与文件大小使用 Foundation 原生格式，不引入第三方国际化库或自定义语言管理器。

邮件主题、正文、联系人姓名、自定义文件夹名称、附件文件名和协议参数保持原始内容。错误提示面向用户本地化，技术诊断保留在日志中。
